Slide 02 · Framework & Architecture

How It's Built

Tech Stack
LayerTechnology
UI FrameworkFlutter (Dart ^3.8.1)
State MgmtRiverpod ^2.6 — reactive, DI-friendly
NavigationGoRouter ^14.6 — role-guarded routes
Real-timeWebSocket (web_socket_channel)
PersistenceSharedPreferences — theme, session
IDsUUID v4 for order & mission tokens
Data Flow
UI← Providers← Repositories← DataSources← WS / REST
Folder Structure
lib/ ├── core/ routing · theme · widgets ├── features/ │ ├── auth/ login + auth state │ ├── splash/ splash screens │ ├── shell/ role-based shells │ ├── customer/ home · cart · checkout · tracking │ ├── worker/ robot control dashboard │ └── robot_status/ telemetry widgets ├── shared/ models · DTOs └── infrastructure/ data sources · DI
Key Decisions
  • Feature-first — each feature owns domain, presentation & providers
  • Single AppColors token file drives all 80+ color references
  • GoRouter redirect guards enforce role access automatically
  • Dual dark/light theme persisted across sessions
